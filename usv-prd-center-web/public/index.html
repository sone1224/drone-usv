    부산 실해역 운용 실제 지도 · 플랫폼별 시나리오

    부산 실지도 열기 ↗

    광안리·태종대·송도·기장·해운대·감천·북항·고리 등 실제 위치에서 모델 A·B·D와 지상통제소 + 해상통제소(지원함)로 운용합니다. 지도는 Google Maps(키 설정 시) 또는 OpenStreetMap·Esri 위성이며, 표적·경계구역은 훈련용 가상 설정입니다.

    여기서 실행

    ‘기본 화면 열기’나 시나리오의 ‘여기서 실행’을 누르면 이 자리에 시뮬레이터가 열립니다. 넓은 화면(1280px 이상)이나 새 창에서 보기 좋습니다.

    설계 도구 · 선체 설계·단가 시뮬레이터

    치수·재질만 바꾸면 성능·단가가 바로

    MAGURA V5 기준 선형 → 흘수·저항·복원성 → 재질별 단가 → 3D 프린트 파일.
    기본값: 모델 B 축소안(4.5 m · 전기추진).

    도구 실행

    새 창으로 열기 ↗

    ‘여기서 실행’을 누르면 이 자리에 설계 도구가 열립니다. 표와 3D 화면이 넓어 새 창이 더 편합니다.

    PRD와 연결해 쓰는 법

    • 모델 B: ‘해양관측용 축소안’으로 시작해 운용 8시간(안)·센서 탑재중량을 판정 카드로 확인
    • 모델 A: 단동·쌍동을 바꿔 3m급 차량 적재·2인 진수 중량을 맞추고 복원성(GM) 확인
    • 모델 D: 레이더·EO/IR 마스트 높이(마스트 전면적·KG/D 비)를 바꿔 복원성과 8시간 순찰 배터리 확인
    • 모델 C: 임무 베이 탑재중량을 ‘페이로드’로 넣어 흘수·속력 여유 확인(임무장비 내부는 다루지 않음)
    • ③ 재질·단가 표로 GFRP·HDPE·3D 프린트 공법을 비교해 저가 양산 방향 결정
    • ④에서 1:N 축척 STL을 뽑아 수조 모형·전시 모형 제작

    주의

    • 유체 계산은 CFD가 아닌 개념설계 단계 준경험식(ITTC-57·Savitsky)이며 ±15~20% 오차가 있을 수 있습니다. 최종 설계 전 수조시험·CFD로 확인하세요.
    • MAGURA V5 형상은 공표 치수와 공개 사진으로 추정한 근사 선형입니다.
    • 재료 단가·공수·두께식 초기값은 가정치입니다. 견적을 받으면 ③ 표에서 고쳐 쓰세요.
    • 3D 화면은 three.js를 인터넷(unpkg)에서 불러옵니다. 인터넷이 막힌 사내망에서는 3D 보기가 나오지 않을 수 있습니다.
