# 수상드론 지상통제소(GCS) 시뮬레이터

`수상드론_PRD.docx`(2026-10-20 초기본)를 바탕으로 만든 지상통제소 운용 시뮬레이터입니다.
설치 없이 브라우저에서 동작합니다(외부 라이브러리·인터넷 불필요).

## 실행

- `index.html` 을 더블클릭해 브라우저(Chrome/Edge)로 엽니다.
- 또는 로컬 서버: `powershell -ExecutionPolicy Bypass -File serve.ps1` 실행 후 http://localhost:8080 접속

## 부산 실지도 운용 (busan.html)

실제 지도(부산 연안) 위에서 모델 A·B·D를 운용하는 검증 시나리오 11종입니다. 시뮬레이터 상단의 '🗺 부산 실지도 운용'으로 엽니다.

| 분류 | 시나리오 |
|---|---|
| 인명구조(A) | 광안리 앞 익수자 구조 · 태종대 갯바위 고립자 수색 |
| 해안감시(D) | 송도·감천 해안 접근 선박 감시 |
| 어장감시(B) | 기장 앞바다 불법조업 감시(증거 영상 확보) |
| 해양오염감시(B) | 해운대 앞바다 유출유 감시 · 감천항 앞 기름 배출 감시 |
| 국가중요시설 순찰(D) | 부산항 북항 부두 보안구역 경계 · 고리원전 앞 해역 경계 |
| 해상통제소 | 외해 관측 · 해상통제소 인계 · 해상통제소 없이 외해 진출(두절 안전 동작) |
| 1인 다척 | 광안리·해운대·북항 3척 동시 운용 |

- 통제소: 지상통제소(한국해양대 인근, 연안 LTE·메시) + 해상통제소(지원함 탑재, 메시 6km). 외해에서 자동 인계.
- 지도: PRD 센터 서버에 `GOOGLE_MAPS_API_KEY`가 있으면 Google Maps, 없으면 OpenStreetMap·Esri 위성.
- 경계구역·요구조자·유출유·미식별 선박·AIS 선박·LTE 기지국 위치는 모두 훈련용 가상 설정입니다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 좌측 | 선단 목록(1인 다척 운용), 선체 추가 진수, 전 선체 경보 목록·확인 |
| 중앙 | 해도: 해안선, 지상통제소·복귀 지정점, LTE 커버리지 한계, 메시 사거리·중계선, AIS 선박, 경로점, 항적 |
| 하단 | 운항·상태 기록, CSV/JSON 추출 |
| 우측 | 선택 선체의 운항 / 상태감시 / 통신 / 임무 탭 |

해도 조작: 드래그 이동, 휠 확대·축소, 선체 클릭으로 선택. '경로점 편집'을 켜면 좌클릭으로 추가, 우클릭으로 마지막 점 삭제.
수동 모드 키보드: `W/S` 추력, `A/D` 타각, `X` 타 중립, `Space` 정지.

## PRD 요구사항 반영

| ID | 요구 | 시뮬레이터 구현 |
|---|---|---|
| COM-02 | 4개 모듈 구조 | 전원·전장 함체·통신·항법을 각각 따로 모델링 |
| COM-03 | 통신 이중화·자동 전환 | 링크 관리기가 우선순위(A·B: LTE→메시→위성, C: 메시→위성→LTE)에 따라 자동으로 전환. 통신 탭에서 링크를 강제로 차단해 시험 가능 |
| COM-04 | 통신 두절 시 안전 동작 | 설정 시간(5~120s)이 지나면 지정점 복귀 또는 정지·표류. 링크가 없으면 원격 명령 전송 불가 |
| COM-05·06 | 방수·열·습도 관리 | 함체 온도·습도·누수 감시, 냉각 유닛 히스테리시스 제어, 제습 |
| COM-07 | 상태감시·경보 | 전압·전류·SOC·온습도·누수 실시간 표시, 주의·위험 경보 및 확인 |
| COM-08 | 운항·상태 기록 | 1초 주기 원격측정 기록, 이벤트 로그, CSV/JSON 추출 |
| COM-09 | 1인 운용 | 운용자 한 명이 여러 척을 운용하고 선체를 추가로 진수 |
| COM-10 | 사이버보안 | 링크 암호화·MAVLink 2 서명 표시(C는 KCMVP 모듈) — 표시만 하며 실제 암호화는 하지 않음 |
| IF-09 | PDU | 채널별 전류 계측과 원격 ON/OFF(운항 제어기·통신 채널은 차단 금지) |
| — | GNSS 교란 | IMU 보조 항법으로 전환하고 위치 오차가 누적됨(해도에 불확도 원 표시) |
| — | 배터리 안전 | SOC 20% 미만이면 자동 복귀, 30%·15%에서 경보 |
| — | 자체 점검(BIT) | 장기 보관 후 점검만으로 운용 가능한지 각 모듈을 검사 |

### 모델별

- **A 인명구조형**: EO/열화상 카메라 영상 시뮬레이션, 요구조자 탐지(약 450m, ±35°), 구조부이 원격 분리(40m 이내면 전달 성공).
- **B 해양관측형**: 경로점 자율 순항(관측 패턴 자동 생성), 기상·수질 센서(NMEA 2000), 유출유 감지 시 상황실 경보(IF-10), AIS 기반 충돌 회피(CPA/TCPA).
- **D 국가중요시설 감시·정찰형**: 원전 앞 가상 경계구역 둘레 반복 순찰, 해상 레이더(6km)·EO/IR·AIS 대조로 미식별 선박 탐지, 접근·침입 경보와 상황실 보고, 추적 감시, 경고 방송·탐조등(비살상, 무장 없음). 임무 탭에 레이더 화면(PPI)과 훈련용 '미식별 선박 투입' 버튼.
- **C 군용 저가 소모형**: 임무 베이 인터페이스(IF-08)의 전원·Ethernet·CAN·체결 상태만 감시합니다. PRD 제외 범위에 따라 임무장비 내부는 다루지 않습니다. AIS 송신은 제어할 수 있으며 기본값은 OFF입니다.

### 고장 주입(상태감시 탭)

누수, 냉각 유닛 고장, GNSS 교란, 배터리 셀 이상을 켜고 끄며 경보와 안전 동작을 시험합니다.

## 참고

- 수치(속도·배터리 용량·소비전력·통신 범위 등)는 PRD의 '안' 값과 가정에 맞춘 시뮬레이션 값이며 확정 사양이 아닙니다.
- 좌표는 부산 앞바다를 기준으로 한 가상 해역입니다.
